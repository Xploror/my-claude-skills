# Reference resume — base format template

A fully anonymized template showing the required structure, section order, and bullet density/style. Every bracketed placeholder must be filled with THIS applicant's real details — never carry over a previous applicant's name, school, employer, or achievements into a new resume. The Summary section is mandatory — it is easy to forget since many people's existing resumes don't have one; always add it.

## Style notes

- Header row pattern: bold title/school on the left, italic dates/location right-aligned on the same or next line — keep it scannable, not prose.
- Bullets are achievement-oriented, not duty-oriented: "Built X, achieving Y" beats "Responsible for X."
- Bullet density: roughly 2-4 bullets per experience entry, 1-2 per project. Trim ruthlessly — a resume is a highlight reel, not a full activity log.
- This structure applies to any field — the placeholders above are field-agnostic on purpose; don't assume a technical/engineering background unless the applicant's actual material is technical.
